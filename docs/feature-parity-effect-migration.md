## Summary

The migrated app preserves the three-game product shape, daily challenge concept, bilingual support, achievements, and the main play loops. The largest improvements are Cloudflare/D1 persistence, server-side validation, Effect-based server workflows, Alchemy infrastructure, and generated solvable Shape Architect practice puzzles.

The main parity gaps are the old Firebase account-linking flow, timer/practice controls, sound/high-touch accessibility controls, richer tutorials/modals, Magic Graph master/grandmaster UI, Sequence Race two-player and teacher-hint UI, and some detailed rank/streak presentation.
