## Summary

The migrated app preserves the three-game product shape, daily challenge concept, bilingual support, achievements, and the main play loops. The largest improvements are Cloudflare/D1 persistence, server-side validation, Effect-based server workflows, Alchemy infrastructure, generated solvable Shape Architect practice puzzles, D1-backed profile/rank summaries, and reusable practice/timed session controls.

Firebase auth, Firestore sync, and account-linking are deprecated by design. Remaining useful non-Firebase parity gaps are streak tracking, sound/high-touch accessibility controls, richer tutorials/modals, Magic Graph master/grandmaster UI, Magic Graph editor/undo flows, and Sequence Race two-player/teacher-analysis/history UI.
