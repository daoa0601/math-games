## Appendix D: Example Games for Inspiration

*Brief descriptions of the three existing games in Math Gymnasium.*

---

### 1. Magic Graph

**Concept:** Graph-based number placement puzzle
**Visual Theme:** Mystical Constellation (starfield, golden glows, celestial magic)
**Math Concepts:** Addition, logical deduction, constraint satisfaction
**Target Age:** Grades 3-8 (Ages 8-14)

**How it works:**
- Players see a graph of empty nodes connected by glowing lines
- Must place numbers (e.g., 1-6) into nodes such that each line sums to a target value
- Lines turn green when correct, red when sum is too high
- Difficulty scales by:
  - Increasing number of nodes and lines
  - Adding pre-filled "fixed" nodes that constrain solutions
  - Larger number ranges

**Key mechanics:**
- Click-to-select number → click-to-place on node
- Visual feedback: line color changes based on sum status
- Hint system: highlights one correct placement
- Undo/Reset options

**Learning value:**
- Mental arithmetic practice
- Logical reasoning under constraints
- Pattern recognition

---

### 2. Sequence Race

**Concept:** Turn-based strategy game where players race using number sequence cards
**Visual Theme:** Track & Field (running stick figures, racing lanes, dust trails)
**Math Concepts:** Arithmetic, geometric, Fibonacci, prime, square, triangular sequences
**Target Age:** Grades 4-8 (Ages 9-14)

**How it works:**
- Player and AI opponent race along a track numbered with a mathematical sequence
- Each turn, play a card matching the next number in the sequence
- First to reach the finish line wins
- AI difficulty scales from predictable (easy) to optimal (hard)

**Key mechanics:**
- Click card to play it
- Turn-based: player → AI → player
- Visual feedback: runners advance along the track
- Sequence type revealed at game start (e.g., "Geometric Sequence: ×2")

**Learning value:**
- Pattern recognition in mathematical sequences
- Strategic thinking (when to use which card)
- Speed and accuracy in sequence completion

---

### 3. Shape Architect

**Concept:** Voxel-based 3D geometry puzzle
**Visual Theme:** Building Workshop (wood grain, blueprints, construction site)
**Math Concepts:** 3D spatial reasoning, volume, coordinate geometry
**Target Age:** Grades 5-8 (Ages 10-14)

**How it works:**
- Players see a "blueprint" (yellow target grid) showing the desired 3D shape
- Must drag and place colored blocks to match the blueprint exactly
- 3D camera allows rotating and zooming to view from all angles
- Difficulty scales by shape complexity and number of pieces

**Key mechanics:**
- Drag-and-drop pieces onto the 3D grid
- Keyboard arrows for fine positioning
- Space bar to rotate pieces (future feature)
- Snap-to-grid with visual/audio feedback

**Learning value:**
- Develops spatial reasoning skills crucial for STEM
- Visualizing 3D objects from 2D blueprints
- Understanding coordinate systems (x, y, z)
- Volume calculation (counting cubes)

---

### Common Patterns Across All Games

**Shared features:**
- **Practice Mode:** Play without tracking stats or achievements (zero pressure)
- **Hint System:** Optional help when stuck
- **Undo/Reset:** Forgiving gameplay encourages experimentation
- **Progress Tracking:** Stats, achievements, rank-up celebrations
- **Responsive Design:** Works on desktop, tablet, and mobile
- **Bilingual:** Full English and Vietnamese support
- **Accessibility:** Keyboard navigation, screen reader support, high contrast mode

**Visual Feedback Philosophy:**
- **Green = Correct** (glow, checkmark)
- **Red = Incorrect** (shake, error icon)
- **Yellow = Partial progress** (pulse, highlight)
- **Gray = Neutral/empty** (outline only)
- **Gold = Complete** (celebration, confetti, star burst)

**Progression Philosophy:**
- Counter-based (games played, puzzles solved, wins) - NO XP points
- 8 ranks: Beginner → Learner → Apprentice → Intermediate → Advanced → Expert → Master → Grandmaster
- Achievements unlock based on milestones (e.g., "First Victory", "30-Day Streak")
