# Game Documentation & Proposals

This directory contains game design documentation for Math Gymnasium.

## Files

### TEMPLATE.en.md
**Game Proposal Template** - Use this template to propose new math games for Math Gymnasium. This comprehensive guide helps teachers structure their ideas in a way that developers can understand and implement.

**Who should use it:** Mathematics teachers, curriculum designers, educational game enthusiasts

**What it contains:**
- Structured sections for game concept, mechanics, and learning objectives
- Curriculum alignment tables (US Common Core + Vietnamese SGK)
- Visual feedback system guidelines
- Difficulty scaling parameters
- Example level templates
- Implementation notes (optional technical details)
- Reference materials and existing game examples

### Existing Game Documentation

- **magic-graph.en.md** - Full specification for the Magic Graph puzzle game

## How to Propose a New Game

1. **Copy the template:** Make a copy of `TEMPLATE.en.md`
2. **Name your file:** Use the pattern `[game-name].en.md` (e.g., `fraction-builder.en.md`)
3. **Fill it out:** Complete as many sections as you can. The more detail, the better!
4. **Submit:** Share with the development team via GitHub Issue (label: `game-proposal`) or email

## What Makes a Good Proposal?

### Essential Elements
- **Clear learning objectives** tied to curriculum standards
- **Concrete example levels** that developers can implement and test
- **Visual feedback system** so players always understand game state
- **Difficulty progression** that scales appropriately for target age groups

### Nice-to-Have Elements
- **Visual theme ideas** with mood and color palette suggestions
- **Real-world connections** that help students see math's relevance
- **Accessibility considerations** for diverse learners
- **Multiple difficulty levels** with specific parameter adjustments

## Review Process

1. **Draft** - Teacher fills out template
2. **Under Review** - Development team evaluates feasibility and educational value
3. **Approved** - Game enters the development queue
4. **In Development** - Engineering team builds the game
5. **Released** - Game goes live in Math Gymnasium!
